# DevTechx Labs · GitHub community

This repository contains DevTechx Labs' organization-wide GitHub community files
and public organization profile. GitHub renders [profile/README.md](profile/README.md)
on the public organization profile when this repository is published as `.github`.

- [Organization setup](ORGANIZATION_SETUP.md) — owner checklist and publishing commands.
- [Asset guide](ASSETS.md) — approved logo, exports, palette, and rebuild instructions.
- [Contributing](CONTRIBUTING.md) · [Code of conduct](CODE_OF_CONDUCT.md) · [Support](SUPPORT.md).
- [Security](SECURITY.md) · [Governance](GOVERNANCE.md).
- [Rights notice](LICENSE) · [Brand assets](BRAND_ASSETS.md).

Issue forms live in `.github/ISSUE_TEMPLATE/`; Actions live in `.github/workflows/`.
The repository name `.github` does not replace this nested configuration directory.
Community defaults apply where a repository has no corresponding local policy;
workflows and licenses do not automatically propagate to other repositories.

The Markdown lint and link-check workflows use read-only permissions and pinned
Action commits. External links are checked weekly and on manual runs; pull requests
check local links to keep third-party outages out of routine review.

of conduct retains its separate CC BY-SA 4.0 license. See [LICENSE](LICENSE).
